# Design Mockups

Esta carpeta contiene los mockups de diseño generados con Stitch para el sistema HR Payroll.

## Mockups Disponibles

### 1. Login Page
**Archivo:** `login-page.[extensión]`
- Formulario de autenticación
- Usuario: admin / Contraseña: admin123
- Responsive: desktop y mobile

### 2. Employees Page
**Archivo:** `employees-page.[extensión]`
- Lista de empleados en tabla
- Formulario para crear empleado
- Estados: loading, empty, error

### 3. Contracts Page
**Archivo:** `contracts-page.[extensión]`
- Lista de contratos
- Formulario para crear contrato
- Badges para tipo y estado

### 4. Payroll Runs Page (si aplica)
**Archivo:** `payroll-runs-page.[extensión]`
- Lista de corridas de nómina
- Formulario de cálculo
- Desglose de deducciones

### 5. Payroll Rules Page (si aplica)
**Archivo:** `payroll-rules-page.[extensión]`
- CRUD de reglas
- Toggle enable/disable
- Agrupación por tipo

## Cómo Usar

1. **Coloca tus mockups aquí** con nombres descriptivos
2. **Formatos aceptados:** PNG, JPG, SVG, PDF
3. **Nomenclatura:** usa kebab-case (ejemplo: `login-page-mobile.png`)

## Implementación

Una vez colocados los mockups, el siguiente paso es:
1. Extraer la paleta de colores
2. Crear componentes reutilizables
3. Implementar páginas según diseño
4. Validar accesibilidad (WCAG AA)

## Notas

- Mantener mockups actualizados con cambios de diseño
- Incluir versiones desktop y mobile cuando sea relevante
- Documentar decisiones de diseño importantes
